AgentXRay 能做什么

Sessions — 跨工具浏览与回放 AI agent 会话：每条消息、每次工具调用的参数与结果、耗时拆分、token 成本。左侧搜索框直接输入过滤列表，按回车全文搜索会话内容（含已被 Claude 清理的历史输入）。
Insights — 聚合分析：哪些工具用得最多、哪里报错、token 花在哪、每天用量趋势。选中某个会话后变为单会话分析。
Prompts — 自动提取你在所有会话里输入过的真人 prompt（滤掉工具输出和系统注入），按目录分组。每条可 ⭐ 收藏入库、优化（Claude 改写）；「分析优化」把相似 prompt 聚成模板并统计效果。
Library — prompt 资产库：标签分类、编辑、搜索。每条有 Claude / Codex / OMP 三个开关，点亮即安装为该工具的 slash command——之后在工具里输 /名字 直接调用，$ARGUMENTS 传参。
⚙ 设置 — 自定义各平台的日志目录（默认已指向本机标准路径）。
